description: What carries over unchanged and what works differently.

Controllers, route decorators, parameter decorators, guards, interceptors, pipes, filters and
`HttpException` classes keep their names and their order. Most controller code moves over
with only its imports changed.

## What is different

| NestJS | Suku |
| --- | --- |
| `@Module()` on a class | `defineModule({ ... })`. `@Module` still works. |
| `providers` | `services`. `providers` is accepted. |
| `{ provide, useClass }` | `singleton(Token, Impl)`, type-checked. The object form still works. |
| `Module.forRoot(options)` | A function: `MyModule(options)`. |
| `exports` controls visibility | One flat container. Every service is visible. |
| `@Injectable({ scope: Scope.REQUEST })` | `@Injectable({ lifetime: 'scoped' })`, or `scoped(Service)`. |
| Request scope bubbles up silently | A singleton depending on a scoped service fails at startup. |
| `ExecutionContext`, `switchToHttp()` | `RequestContext`, injectable. |
| `Reflector.get(key, handler)` | `ctx.getMetadata(key)`. |
| Interceptors return an `Observable` | `async (ctx, next) => await next()`. No RxJS. |
| `class-validator` and `ValidationPipe` | Any Standard Schema: `@Body(schema)`. |
| `ConfigModule.forRoot()` | `defineConfig(name, schema)` and `Env.load()`. |
| `NestFactory.create(AppModule)` | `Suku.create(AppModule, { adapter })`. |
| Express or Fastify request objects | Fetch `Request` and `Response`. |
| `Test.createTestingModule()` | `Suku.create({ ..., configureServices })` and `app.handle()`. |

## Scopes are strict

This is the change most likely to surprise you. In NestJS a request-scoped provider quietly
makes everything that depends on it request-scoped. In Suku lifetimes are explicit and
checked.

```text
Captive dependency: UsersController (singleton) depends on CurrentUser (scoped).
```

Fix it by making the consumer scoped, `@Controller({ path: 'users', lifetime: 'scoped' })`,
or by resolving the scoped service from `ctx.provider` inside the handler.

## Interceptors without RxJS

```ts
// NestJS
intercept(context, next) {
  return next.handle().pipe(map((data) => ({ data })));
}

// Suku
async intercept(ctx, next) {
  return { data: await next() };
}
```

## Middleware is simpler

No `configure(consumer)` and no `forRoutes`. Put middleware on a module, on a controller, or
make it global.

```ts
defineModule({ controllers: [AdminController], middleware: [auditTrail] });
```

## Not available yet

Lifecycle hooks, WebSocket gateways, microservice transports, GraphQL and OpenAPI generation
are not part of Suku today.
