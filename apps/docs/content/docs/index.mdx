Suku is a lightweight TypeScript backend framework built from four ideas: **routes**,
**features**, **middlewares** and **services**. Routes are typed by their schemas, and
services come from a dependency injection container modelled on .NET's.

```ts title="main.ts"
import { Routes, Suku, feature, route, singleton } from '@sukujs/core';
import { nodeAdapter } from '@sukujs/platform-node';
import { z } from 'zod';

class UsersService {
  find(id: number) {
    return { id, name: 'Ada' };
  }
}

@Routes('/users')
class UsersRoutes {
  constructor(private readonly users: UsersService) {}

  findOne = route.get('/:id', {
    params: z.object({ id: z.coerce.number() }),
    handle: ({ params }) => this.users.find(params.id),   // params.id is a number
  });
}

const UsersFeature = feature('users', {
  routes: [UsersRoutes],
  services: [singleton(UsersService)],
});

const app = await Suku.create({ features: [UsersFeature], adapter: nodeAdapter() });
await app.listen(3000);
```

## The four ideas

<Cards>
  <Card title="Routes" href="/docs/routes">
    A route is a typed object. Its schemas validate the request and type the handler, so
    nothing is written twice. Group routes in a class, or use them on their own.
  </Card>
  <Card title="Features" href="/docs/features">
    A feature bundles the routes, services and middlewares of one part of your app.
  </Card>
  <Card title="Middlewares" href="/docs/middlewares">
    One concept for everything that wraps a request: logging, authentication, caching, CORS.
  </Card>
  <Card title="Services" href="/docs/dependency-injection">
    Declared with a class or without one. Singleton, scoped and transient lifetimes, a scope
    per request, and startup validation.
  </Card>
</Cards>

## Packages

| Package | Purpose |
| --- | --- |
| `@sukujs/core` | Routes, features, middlewares, validation, config, logger. |
| `@sukujs/di` | The container. Usable on its own, without HTTP. |
| `@sukujs/crypto` | JWT, passwords, signed and encrypted values. Works on its own. |
| `@sukujs/security` | CORS, security headers, CSRF protection, rate limiting. |
| `@sukujs/graphql` | Class-based GraphQL resolvers. Optional. |
| `@sukujs/platform-node` | Adapter for `node:http`. |
| `@sukujs/platform-bun` | Adapter for `Bun.serve`. |

None of them has a runtime dependency. `@sukujs/core` re-exports the container's decorators and
registration helpers, so application code usually imports from one place.
